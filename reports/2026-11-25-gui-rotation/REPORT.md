# 图形界面与轮流出块

## 修改

- 新建链使用 VDF 轮流出块：32 块一轮、最多 5 个生产者、200 ms 时间片、65536 次 VDF 迭代。节点使用每块最多 6000 笔交易、2000 笔步长。加入链和切回已有链使用原创世参数。
- 节点页显示出块方式、时间片、已选成员数量、当前生产者。停止或断线后清空两个实时字段，保留链配置。
- 删除页面副标题、切链说明、昵称说明、重复聊天室状态、钱包解释和网络长段提示。保留地址选择、钱包退出/切换、实际状态与错误。
- Windows 新工具链中，发送协程的结构化绑定导致发送资源未释放。改为显式局部变量后，原有关闭连接测试通过，未增加等待或手动扣减计数。
- 自动资助请求的临时文件名去掉重复公钥，保留 128 位随机值和同目录原子重命名。实测原路径 277 字符无法创建，缩短为 212 字符后创建和重命名成功。
- 明确 VDF 配置的命名空间，兼容 Boost 1.90 新增的 `boost::asio::config`。

## 验证

前端 32 项测试、TypeScript 检查和 Vite 生产构建通过。最终静态文件为 `index-DpNI9TWR.js`、`index-DNTRLtwD.css`。

Windows 首轮 CTest 运行 39 项，34 项通过。5 项失败分别为发送资源释放、交易步长网络测试，以及 3 项自动资助测试。修复后重测受影响的 27 项，全部通过，用时 324.79 秒；合并结果为 39/39 通过，详见 `validation.json`。

实际浏览器检查了聊天、账户、邀请地址下拉框、创建窗口、出块状态、停止与恢复节点。停止后成员数和生产者显示 `—`；恢复后重新显示。控制台无错误。测试使用独立链和钱包。截图为 `gui-chat.jpg` 和 `gui-rotation.jpg`。

`ClassroomRotation` 覆盖新建链参数、邀请与发现参数、节点实时状态、成员领币与发消息、停止/重启、旧链切换及余额和序号保留。已有网络测试改为比较同高度区块，避免轮流出空块时两次读取链头产生时间差。

验证结束后停止测试进程，清理 232 个 RocksDB 数据库和 35 个 SQLite 索引，释放 221,645,145 字节。测试配置与结果保留。

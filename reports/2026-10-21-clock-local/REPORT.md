# 学习辅助时钟与候选调度：本地实现和验收

日期：2026-10-21。基线：`933905448951c600156a8ad2a0b3c3a895916fb5`。实现位置：`D:\Project\Chain`。范围为本地代码、训练工具、正确性验证和 GitHub 同步；未连接云端执行部署或实验。

## 实现

- 新增 `robust`、`shadow`、`learned` 模式，原 `legacy` 默认不变。通过单调时间积分实现连续应用时钟、正速率、±1000ppm 默认校正上限和来源过期保持。系统时间、区块编码、账户/EVM 规则、同父候选和分支排名不变。
- 四时间戳按配置的监听地址去重，默认要求三个新鲜远端来源。请求令牌保持同连接关联；固定地址白名单仅服务可信成员实验，不是密码学认证。加固不可信时间戳的整数边界处理。
- 32 个负载和多源特征，包含 1/5/30 秒历史；独立观察线程执行固定双分位数模型，准备/提交耗时和候选结局可导出。历史、工作记录、来源、遥测队列及输出行数均有上限。模型不能直接设置时间目标，只能增加稳健预算并衰减增益。
- 模型文件校验版本、特征顺序、归一化、域、系数、分位点和标签来源，记录文件与数据 SHA-256。坏模型、越域观测和过期预测回退；失去来源时调度预算立即失效，不依赖观察线程继续运行。
- 新增 `bounded` 调度：窗口足够时补入当前轮，否则提前准备未来轮；冻结单调截止、时钟版本、父哈希、高度、状态版本和特征版本。每轮在准备前消耗唯一尝试机会，父版本不符或迟到则丢弃。收到的有效迟到块仍走原验证路径。退出不创建绕过调度条件的新候选。
- 本地 A/B/C/D 开关、旁路模式、缺模型及不足来源测试接入 CTest。说明和命令见 [时间模块文档](../../Time/README.md)。

## 训练记录

附带模型为**模拟验证模型**，没有用十台实机数据训练。固定种子 `20261021`，96 个独立 run，每个 96 个 500ms 步长，共 9,216 行。训练 5,280 行、校准 672 行、测试 3,264 行；含混合故障的整个 run 留在测试集，各节点和相邻窗口不跨集合。校准取已知场景的保守残差分位数，测试集不参与校准。

| 预测头 | 测试完整标签数 | 名义分位数 | 测试经验覆盖率 | 混合故障覆盖率 |
|---|---:|---:|---:|---:|
| 绝对时间误差 | 3,264 | 95% | 99.05% | 98.44% |
| 本地准备耗时 | 3,200 | 95% | 97.09% | 95.65% |

保留 64 条准备删失记录，准备头的覆盖率仅针对完整观测。覆盖率来自受控模拟，既不是实机误差保证，也不是抗任意非对称时延的安全证明。特征域外回退；真实训练必须引入独立标定参考，不把邻居中位数或已有同步器输出当真值。

原始模拟数据位于被忽略的 `build/clock-learning/simulation.jsonl`，可用生成器重建。数据 SHA-256 为 `41771a379d3f6493bfd9b599c913cc6f9b7324d35e3c77d6b6a079e55c64ad04`。模型及其完整 SHA-256、各场景覆盖率、run 分割记录见 [training.json](training.json)。模型文件固定 LF 行尾，保证 Git/Windows/Linux 检出的字节校验一致。

## 本地正确性验证

构建环境为 Windows、GCC 15.2.0、CMake 3.30.3、Python 3.12.7、NumPy 1.26.4。采用 Release 构建，数据库同步写入，测试目录为独立 `build/clock-check-20261021-*`。

```powershell
cmake -S . -B cmake-build-release -DCHAIN_TEST_DATA_ROOT=D:/Project/Chain/build/clock-check-20261021-02
cmake --build cmake-build-release --parallel 2
ctest --test-dir cmake-build-release --output-on-failure `
  --output-junit D:/Project/Chain/reports/2026-10-21-clock-local/ctest.xml
```

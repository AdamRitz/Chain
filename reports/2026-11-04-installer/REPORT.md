# 2026-11-04 Windows 安装速度与目录选择

0.2.1 默认双击显示目录选择页，用户可输入或浏览 D 盘等目录；继续后自动安装并启动。标准包从 229,574,403 字节降至 13,879,808 字节（218.94 → 13.24 MiB，减少约 94%）。另提供 227,095,734 字节（216.58 MiB）的完整离线包。

## 原因与改动

原模板为简化点击次数，默认开启被动安装，跳过包括目录在内的向导页面，仅 `/WIZARD` 可选择目录。包内携带完整 WebView2 离线安装程序，且使用整块 LZMA 压缩。即使系统已有 WebView2、运行时安装部分被跳过，后续文件仍处在同一压缩流中。

本次默认保留目录页，其他非必要页面继续跳过。目录在卸载旧版本之前确定；同版本更换目录也清理旧程序。同路径被动升级继续保留已有网络规则，更换路径按原有 helper 流程清理旧路径规则。被动维护不再读取未创建的单选控件，显式选择重新安装。初始化检查目标及注册的旧目录，目录选择后复查目标中的运行程序。

标准包使用内置 WebView2 引导程序，系统已有运行库时直接跳过，缺少时联网下载安装；可选离线配置携带完整运行库。文件改为独立 LZMA 压缩，跳过大运行库时无需先解码它所在的整块流。依赖检测、安装失败处理和普通卸载保留账户数据的行为沿用 Tauri 模板。依据：[Tauri 安装模式](https://v2.tauri.app/distribute/windows-installer/#webview2-installation-options)、[微软运行库分发](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution)、[NSIS 压缩说明](https://nsis.sourceforge.io/Docs/Chapter4.html#SetCompressor)。

安装目录控制程序文件。账户和链数据继续保存在 `%LOCALAPPDATA%/edu.chain.classroom`，不会随程序目录搬移。本次没有改动账户、合约、节点共识或 FISCO 测试方法。

## 实际包验证

在同一台 Windows 电脑、已有 WebView2 156.0.4314.58、D 盘全新隔离目录进行。每项一次，从启动安装器计至退出，包括文件解压、复制和安装注册操作，不包括下载、用户选择目录的停留或应用启动。计时是本机观测，受文件缓存、磁盘和系统负载影响，不能承诺其他电脑同样耗时。

| 操作 | 耗时 | 结果 |
| --- | ---: | --- |
| 0.2.0 旧包全新安装 | 17.527 秒 | 成功 |
| 0.2.1 标准包原目录升级 | 1.754 秒 | 成功 |
| 旧目录网关运行时，指定不同新目录安装 | 0.259 秒 | 返回 2，拒绝覆盖，旧文件保留 |
| 0.2.1 同版本移至中文和空格目录 | 5.136 秒 | 成功，旧主程序移除 |
| 0.2.1 标准包全新安装 | 1.210 秒 | 成功 |
| 0.2.1 离线包全新安装 | 2.814 秒 | 成功，已有运行库被跳过 |

三次普通卸载均成功，耗时 3.638–3.784 秒。两包内 20 个运行文件与清单 SHA256 全部一致，标准包与离线包的运行载荷清单完全相同。原用户数据目录 400 个文件、约 75 MB 的内容前后摘要一致；恢复原来的安装位置记忆值，未替换现有程序目录。前端 8 项测试通过，两种正式安装包构建成功，新增离线配置未写回主配置。

界面工具读取到默认第一页为“选择安装位置”，包含可编辑目录、浏览按钮和数据目录说明，见 [目录页可访问性记录](directory-page.txt)。工具两次输入均返回 `failed to activate captured window`，截图仅捕获桌面背景，因此没有声称完成鼠标点击浏览或可视截图验收；自定义中文目录安装和升级由同一正式安装器的命令行模式完成验证。未通过其他 UI 自动化方式绕过工具失败。

未卸载系统 WebView2 来模拟缺失环境，因此未实测缺少运行库时的微软下载速度、完全离线安装运行库，以及真实有规则情况下的提权/防火墙清理。此次没有修改防火墙。没有因打包变更重复无关的区块链性能实验。

复现入口：[RunQA.py](RunQA.py)，详细数据和安装包摘要：[validation.json](validation.json)。脚本要求当前用户没有注册的正式安装，以免替换在用版本，并要求全新的隔离测试目录。正式包输出位于 `Classroom/release/`，二进制通过 GitHub Release 分发，不纳入 Git 源码。
